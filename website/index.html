cursor-server

Local agents. Your repos. Your host.

An HTTP API that runs Cursor agents against checked-out repositories on a home-lab machine, reachable over Tailscale from the IDE you already use.

View source Get started

Built for the machine that already holds your code

Keep clones on your host. Clients send prompts; the server does the work in place.

  • Run locally Agents operate against repositories under your own REPOS_ROOT.
  • Work remotely Tailscale clients hit a small HTTP API from home or work laptops.
  • Automate safely Async tasks, scheduled reviews, and a stage-observable harness.

From request to result

  1. Send a prompt and repository name from your IDE or automation.
  2. cursor-server validates the repo and starts a local agent run.
  3. Stream progress, inspect results, or let scheduled jobs handle the loop.
